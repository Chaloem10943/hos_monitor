SIGNED AGENT RELEASE

สั่งอัปเดต Agent จากส่วนกลาง

Agent รับเฉพาะไฟล์ .hmagent ที่มีลายเซ็นถูกต้อง และอัปเดตเฉพาะไฟล์ Agent ที่กำหนดไว้เท่านั้น

การกระจายรุ่น7 วันAgent รับคำสั่งใน heartbeat รอบถัดไป

1. นำเข้า Agent release

สร้างบนเครื่องพัฒนาด้วย Build-AgentRelease.ps1

2. สั่งอัปเดต

เลือกทุกเครื่อง หน่วยงาน หรือ Asset ID · เครื่องที่มีเวอร์ชันตรงกับรุ่นเป้าหมายแล้วจะนับว่าสำเร็จโดยไม่ติดตั้งซ้ำ
